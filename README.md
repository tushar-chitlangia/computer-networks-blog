# computer-networks-blog
Computer Networks Blog — The Link Layer

## About
This project is an educational blog created as part of the Computer Networks assignment. It explains the main concepts of: The Link Layer using simple explanations, diagrams, practical examples, and an interactive quiz.

## Topics Covered
- Link-layer basics and frame structure
- Error detection and correction
- Parity, checksum, and Cyclic Redundancy Check (CRC)
- Random-access and taking-turns protocols
- DOCSIS
- Link virtualization
- Multiprotocol Label Switching (MPLS)

The aim is to present the link-layer concepts in an accessible and visually engaging format to support learning and revision.
