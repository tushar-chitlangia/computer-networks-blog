When we browse a website or stream a video, data crosses several network links. The link layer moves a packet over one link at a time by putting it inside a frame. It also helps devices share a link and check for transmission errors. The network layer handles the wider route; the link layer handles each local step [1].

1. What does the link layer do?

CORE IDEA

The network layer handles the wider route; the link layer handles one link at a time.

The link layer sits between the network layer and the physical layer. Its data unit is a frame, which carries a network-layer packet plus link-specific information. In Ethernet, this includes source and destination MAC addresses and a Frame Check Sequence (FCS) for detecting accidental damage.

Think of a long trip made of several legs: the network layer helps choose the overall route, while the link layer gets the data across each individual link. Depending on the technology, link-layer services include framing, local addressing, medium access, and error detection. Some links retransmit damaged frames; others leave recovery to a higher layer.

2. Error detection and correction

Noise can change a transmitted bit from 0 to 1 or from 1 to 0. Error detection adds check information so a receiver can notice many such changes. Error correction uses extra information to locate and repair certain errors. They are related, but they are not the same [1].

Parity

Adds one bit so the count of 1s is even or odd.

1011 + 1 = 10111With even parity, the four 1s pass the check. One flipped bit is detected, but two flipped bits may go unnoticed.

Checksum

Breaks data into fixed-size words and adds them using an agreed rule.

The receiver repeats the calculation. It is simple, but certain error patterns may still pass.

CRC

Uses modulo-2 polynomial division and appends the remainder.

It detects many errors, including many burst errors. It does not repair the data.

Parity: The bits 1011 contain three 1s. With even parity, a 1 is added, producing 10111. A single-bit change makes the parity check fail, but one parity bit cannot say which bit is wrong. Two-dimensional parity can locate and correct some single-bit errors.

Checksum: The sender adds fixed-size words and sends a check value. The receiver repeats the calculation and compares the result. The Internet checksum is used by protocols such as TCP and UDP; it is not a universal link-layer checksum.

CRC: The sender divides the bit pattern by an agreed generator using modulo-2 arithmetic and sends the remainder. The receiver checks it again. Ethernet uses a CRC-based FCS [1]. A successful check reduces the chance of undetected corruption, but no check is a guarantee that every possible error will be caught.

3. Who gets to use a shared link?

When several devices use one channel, they need rules for deciding when to send. Without rules, transmissions may collide. Medium Access Control (MAC) protocols manage this problem. The main approaches are random access and taking turns [1].

Random access: devices compete

In ALOHA, a device sends and tries again after a random delay if needed. Carrier Sense Multiple Access (CSMA) checks whether a channel seems busy before sending. Traditional shared, half-duplex Ethernet used CSMA/CD to detect collisions and retry. Wi-Fi uses CSMA/CA, which tries to avoid collisions with channel sensing and random backoff. Modern switched full-duplex Ethernet normally avoids the shared-channel collision situation.

Taking turns: access is organized

With polling, a controller asks devices to send one by one. With token passing, only the device holding a special token may transmit. Taking turns can reduce collisions, but polling uses control messages and a token system must handle a lost token. The best method depends on the network.

4. DOCSIS: cable broadband

DOCSIS means Data Over Cable Service Interface Specification. It carries broadband data over a hybrid fiber-coaxial (HFC) network: fiber reaches a neighborhood node, and coaxial cable connects the node to homes [2].

Downstream means data travelling from the provider to homes; upstream means data travelling from homes back to the provider. Because several cable modems share upstream capacity, DOCSIS coordinates when they can transmit. The modem can request an opportunity, and the provider-side Cable Modem Termination System (CMTS) schedules upstream resources. That is why DOCSIS is a useful real-world example of controlled medium access [2].

5. Link virtualization and MPLS

Link virtualization presents a logical network connection while hiding some details of the physical equipment. A common example is a Virtual LAN (VLAN), which separates groups of devices even when they share switching hardware. The physical network remains shared, but the logical groups are kept separate [1].

Multiprotocol Label Switching (MPLS) forwards packets using short labels inside a provider network. In common diagrams it is sometimes called “Layer 2.5” because the label is placed between the link-layer header and the network-layer packet. That is an informal description, not a separate official OSI layer [4].

At the network edge, an ingress router adds a label (push). Core Label Switching Routers use the label to choose the next hop and may replace it (swap). At the exit, the egress router removes the label (pop). The selected route is called a Label Switched Path (LSP). MPLS helps providers manage paths and quality of service and support services such as VPNs. A label does not encrypt traffic by itself [3, 4].

EASY WAY TO REMEMBER MPLS

Push at entry → swap along the path → pop at exit.

6. How the ideas fit together

Imagine someone watching a film at home through cable broadband. DOCSIS manages access between the modem and the provider. On a Wi-Fi link, MAC rules help devices share the wireless channel. A frame check can detect accidental corruption, and MPLS may guide traffic through the provider's core. Each mechanism has a different job; together they support one end-to-end service.

Key takeaways

  • A frame carries a packet across one link.
  • Parity, checksum and CRC detect some errors; detection is not the same as correction.
  • Random access means competition; polling and token passing organize turns.
  • DOCSIS coordinates cable broadband access, especially upstream sharing.
  • Link virtualization creates logical separation or paths; MPLS uses labels and does not automatically encrypt traffic.
